# Как описать анимацию техники

Каждое упражнение — запись в `js/data/moves/<группа>.js` (`export const M = {id: {...}}`). Движок рисует фигуру-манекен, снаряд и плавно гоняет позу «старт» → «финиш» → «старт». Движок (`js/anim/*`) и `kit.js` не меняем — только свой файл группы.

## Система координат
- Мир без масштаба, кадр подстраивается сам (рамка 3:2 вокруг фигуры). **Пол — y = 214**, ось y вниз.
- В профиль человек **смотрит вправо**. Стоя щиколотка на y ≈ 209 (`ANKLE_Y`).
- Углы — направление сегмента **по часовой от «вверх»**: 0 — вверх, 90 — вперёд (вправо), 180 — вниз, 270 — назад (влево). Можно выходить за 360 и в минус — интерполяция линейная.
- Длины: корпус (таз→плечо) 54, шея 9, голова r≈12, плечо 31, предплечье 28, кисть 7, бедро 44, голень 42, стопа 15 (пятка 5).

## Поза
```js
{root: 'an', at: [180, 209],   // какая точка стоит в at (по умолчанию 'hip')
 t: 0,                          // корпус: направление таз→плечи (0 — прямо, 70 — наклон вперёд, 270 — лёжа головой назад)
 hd: 0,                         // наклон головы относительно корпуса
 a: [180, 180],                 // ближняя рука: [плечо, предплечье, (кисть)]
 a2: [...],                     // дальняя рука (если нет — как ближняя)
 l: [180, 180, 90],             // ближняя нога: [бедро, голень, стопа] (стопа 90 — носком вперёд, 0 — носком вверх)
 l2: [...],                     // дальняя нога
 ik: {a: [x, y], l: [x, y]},    // ЛУЧШЕ углов: кисть / щиколотка придут в точку сами (a, a2, l, l2)
 ikb: {a: 1}}                   // сторона сгиба: по умолчанию колено вперёд (+1), локоть назад (−1)
```
- `ik` может быть дугой рычага: `{c: [x, y], r: 100, ang: 76}` — рукоять на дуге вокруг оси (рычажные тренажёры Impulse, разгибание/сгибание ног — щиколотка по дуге вокруг оси колена).
- `root` не ставь на конечность, у которой есть `ik`.
- Точки фигуры (для `at`, `root`, привязок снаряда): `hip sh nk hd shN shF hpN hpF el wr hn el2 wr2 hn2 kn an he to ft kn2 an2 he2 to2 ft2` (`hn` — центр кисти, `ft` — середина стопы, `…2` — дальняя сторона).

## Описание движения
```js
id: {s: [...снаряд], a: {...старт}, b: {...финиш},
     v: 'f',          // вид спереди (махи в стороны, отведения, наклоны в сторону)
     tempo: 'hold',   // 'rep' по умолчанию; 'hold' — удержание (b чуть отличается от a — «дыхание»); 'fast' — кардио
     m: ['quads'],    // свои подсвеченные мышцы, если группа g из каталога не подходит:
                      // quads hams glutes calves gmed chest lats rear delt biceps triceps abs
     fit: [[x, y]],   // точки, которые должны попасть в кадр (верх стойки и т. п.)
     la: 'Внизу', lb: 'Вверху'}  // подписи старт/финиш (по умолчанию «Старт»/«Финиш»)
```

## Детали снаряда (`s`)
Слой `z`: дальняя нога 1, дальняя рука 2, **снаряд 3 по умолчанию**, корпус 4, голова 5, ближняя нога 6, ближняя рука 7; деталь рисуется на z+0.5. Большие рамы сзади — `z: -1`; то, что в ближней руке или перед телом, — `z: 8`.
- `rect {x,y,w,h,r,c:'steel'|'dark'|'pad'|'hi'|'plate',rot,ox,oy}`, `line {p:[[x,y],…],w,c}`, `circ {x,y,r,c}` — рамы и стойки.
- `pad {x,y,w,h,rot,ox,oy}` — мягкая подушка (сиденье, спинка, валик-упор) с бликом.
- `bench {x,y,w, back:{ang,len}}` — скамья: верх подушки на y, ножки до пола; спинка поднимается влево от x (ang 0 — плоско, 90 — вертикально).
- `seat {x,y,w, back:{ang,len}}` — сиденье тренажёра на стойке.
- `mat {x,w}` — коврик. `box {x,y,w}` — тумба/ящик.
- `stack {x,top,w,lift, cable:{to:'hn', via:[[x,y],…]}}` — весовой стек; верхние блоки поднимаются с движением на `lift`; трос от блоков через ролики к точке.
- `pulley {x,y}`, `cable {from, to, via, handle:false}` — ролик и трос (from/to — точка `[x,y]` или имя точки фигуры).
- `db {at:'hn'}` — гантель; `bb {at, r}` — блин штанги в профиль (r 21 — штанга, ~14 — EZ); `bar {a:'hn', b:'hn2', ext, pr, plates}` — гриф спереди.
- `lever {from:[ось], to:'hn', w}` — рычаг тренажёра от оси к рукояти; `handle {at}` — рукоять; `roller {at, r, arm}` — валик у голени; `plat {at:'ft', ang, w}` — платформа под стопой; `rail {p}` — направляющая; `pullbar {x,y,w}` — перекладина; `smith {x,top}` — стойка Смита; `disc {x,y,r}` — блин; `bike {x}` — велотренажёр.
- Привязка к телу: строка `'hn'` или `{p: 'hip', d: [dx, dy]}`.

## Проверка — обязательно глазами
1. `node tools/pose-points.mjs <id>` — координаты суставов старта и финиша (куда ставить скамью, гриф, рукояти).
2. Кадры: `node tools/pageshot.mjs "http://localhost:8767/tools/anim-preview.html?ids=a,b,c" /путь/кадры.png 1100` и **посмотри картинку** (Read). Колонки — старт, середина, финиш.
3. `node --test tests/anim.test.js` — всё должно пройти (ничего не уходит под пол, детали известны).

Критерии: техника как в `EX[id].setup/how` (`js/data/exercises.js`, `js/data/library.js`); суставы гнутся по-человечески (колено не назад, локоть не наизнанку); руки на рукоятях, стопы на полу/платформе, тело на скамье/сиденье; тренажёр похож на тренажёр из зала (`img/<img>.jpg`); амплитуда реальная; рабочие мышцы подсвечены; ракурс — тот, где движение видно.
