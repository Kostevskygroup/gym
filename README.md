# Мой зал

Личный дневник тренировок для iPhone: программа на тренажёрах моего зала, подходы, таймер отдыха, техника на фото тренажёров, прогресс, вес и талия.

Открыть: **https://kostevskygroup.github.io/gym/**

## Установка на iPhone

1. Открой ссылку в **Safari**.
2. «Поделиться» → **«На экран „Домой“»** → «Добавить».
3. Дальше открывай только через иконку. У приложения на экране «Домой» своё хранилище, отдельное от вкладки Safari.

Перенос записей из старой версии: в старой версии «Тело» → «Скопировать копию», в новой «Тело» → «Вставить текст» → «Восстановить». Записи объединяются, ничего не удаляется.

## Где хранятся данные

Только на телефоне: `localStorage` (тренировки, замеры, настройки) и IndexedDB (свои фото). Сервера нет.

- **Если удалить иконку или сменить телефон, без резервной копии всё пропадёт.** «Тело» → «Сохранить копию файлом» → «Сохранить в Файлы» (iCloud Drive). Приложение само напомнит про копию.
- Перед каждой записью сохраняется предыдущая версия данных. Если данные повредятся, приложение откатится на неё.
- Работает без интернета (service worker). Новая версия ставится по кнопке «Обновить», данные при этом не трогаются.

## Что внутри

- `index.html`, `styles.css`: оболочка и стили. Сборки нет, чистые ES-модули.
- `js/data/equipment.js`: **оборудование зала** (13 тренажёров по фото в `img/`).
- `js/data/exercises.js`: упражнения. У каждого есть тренажёр из `EQUIP`, группа мышц для замен и текст техники.
- `js/data/program.js`: исходная программа из трёх этапов. Правки из редактора хранятся у пользователя поверх неё.
- `js/data/guides.js`: метки на фото тренажёров для экрана «Техника».
- `js/logic.js`: цели (двойная прогрессия, перерывы, колени), рекорды, разминка, замены.
- `js/backup.js`: проверка, нормализация и слияние данных.
- `js/store.js`, `js/workout.js`: хранение и идущая тренировка.
- `js/views/*`: экраны.

## Правки

```bash
npm test          # все расчёты и правило «только тренажёры зала»
npm run build     # пересобрать sw.js: без этого телефон не увидит обновление
```

Потом коммит и пуш в `main`. GitHub Pages опубликует сам.
