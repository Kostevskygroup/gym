# Мой зал

Личный дневник тренировок для iPhone: программа на тренажёрах моего зала, подходы, таймер отдыха, техника на фото тренажёров, прогресс, вес и талия.

Открыть: **https://kostevskygroup.github.io/gym/**

## Установка на iPhone

1. Открой ссылку в **Safari**.
2. «Поделиться» → **«На экран „Домой“»** → «Добавить».
3. Дальше открывай только через иконку. У приложения на экране «Домой» своё хранилище, отдельное от вкладки Safari — поэтому после установки войди в облако ещё раз.

На новом телефоне приложение само проведёт по шагам: короткая анкета (имя, цель, дни, опыт, что беспокоит, упор) → программа → облако → установка.

## Как пригласить человека

В приложении: аватар справа вверху → «Облако» → **«Пригласить человека»**. Создаётся одноразовый код на 7 дней и открывается «Поделиться» — сообщение со ссылкой, шагами установки и кодом. Приглашать может только владелец (аккаунт, созданный мастер-кодом из `.secrets/invite.txt`).

## Облако (синхронизация)

Сервер — `sync-server/` (AWS Lambda + S3 в Ирландии), разворачивается `tools/deploy-sync.sh` (нужен `aws login`). Данные шифруются на телефоне (PBKDF2 → AES-GCM), сервер хранит только шифр и хэш пароля. Один аккаунт — на любом количестве телефонов; две копии сливаются без потерь (удалённое остаётся удалённым). Мастер-код приглашения — только в `.secrets/`, в git не попадает.

## Где хранятся данные

Только на телефоне: `localStorage` (тренировки, замеры, настройки) и IndexedDB (свои фото). Сервера нет.

- **Если удалить иконку или сменить телефон, без резервной копии всё пропадёт.** «Тело» → «Сохранить копию файлом» → «Сохранить в Файлы» (iCloud Drive). Приложение само напомнит про копию.
- Перед каждой записью сохраняется предыдущая версия данных. Если данные повредятся, приложение откатится на неё.
- Работает без интернета (service worker). Новая версия ставится по кнопке «Обновить», данные при этом не трогаются.

## Что внутри

- `index.html`, `styles.css`: оболочка и стили. Сборки нет, чистые ES-модули.
- `js/data/equipment.js`: **оборудование зала**: 13 тренажёров по фото в `img/` плюс свободные веса (штанга с блинами, EZ-гриф).
- `js/data/exercises.js`: упражнения. У каждого есть тренажёр из `EQUIP`, группа мышц для замен и текст техники.
- `js/data/library.js`, `js/data/meta.js`: библиотека упражнений с нагрузкой на суставы (0/1/2) — основа замен, помощника и защиты от боли.
- `js/builder.js`: помощник «Собрать программу» по анкете.
- `js/coach.js`: рекомендации по истории (застой, боли, пропуски, регулярность, вес).
- `js/sync.js`, `js/sync-crypto.js`: облако и шифрование.
- `js/data/program.js`: исходная программа из трёх этапов. В конце каждой тренировки идёт пресс кругом из трёх упражнений: стабилизация → скручивание → анти-вращение/бок. Правки из редактора хранятся у пользователя поверх программы.
- `js/data/guides.js`: метки на фото тренажёров для экрана «Техника».
- `js/logic.js`: цели (двойная прогрессия, перерывы, колени), рекорды, разминка, замены.
- `js/backup.js`: проверка, нормализация и слияние данных.
- `js/store.js`, `js/workout.js`: хранение и идущая тренировка.
- `js/views/*`: экраны.

## Правки

```bash
npm test          # все расчёты и правило «только тренажёры зала»
npm run e2e       # сквозной прогон в настоящем Chrome (нужен сервер на :8767: python3 -m http.server 8767)
npm run build     # пересобрать sw.js: без этого телефон не увидит обновление
```

Потом коммит и пуш в `main`. GitHub Pages опубликует сам.
