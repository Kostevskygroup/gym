# Правила для агентов — приложение «Мой зал»

- **Только тренажёры зала.** Любое упражнение — в программе, заменах, редакторе и будущих версиях — ссылается на тренажёр из `js/data/equipment.js` (фото в `img/`). Новый тренажёр появляется только с фото от владельца. Это проверяет `tests/data.test.js`.
- **Не ломать историю.** Ключи `EX` не удалять и не переименовывать: старое помечать `retired:1` и убирать из программы. Если меняется формат данных — поднять `DB_V` и добавить миграцию в `normalizeDB`.
- **Перед пушем:** `npm test` зелёный, затем `npm run build` (иначе телефон не получит обновление). Каждое изменение — сразу commit + push в `main` (conventional commits).
- Без сборки и зависимостей: чистые ES-модули, тесты на `node --test`. Расчёты — в чистых модулях (`logic.js`, `backup.js`, `program.js`, `stats.js`) с тестами.
- Пользовательский текст выводить только через `esc()`.
- Техника: фото тренажёра с метками (`guides.js`, координаты в пикселях фото 520×693) + свои фото владельца. Чужие фото из интернета в репозиторий не класть: авторские права.
- Данные владельца живут только на телефоне. В репозиторий их не класть.
